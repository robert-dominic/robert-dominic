### 👋 About Me

I'm **Robert Dominic**, a Frontend Engineer building responsive, high-performance web apps with a strong focus on user experience, clean architecture, and polished interface design. I run **WebNova Studio**, taking on freelance client work and building products of my own — most recently focused on tools built for the realities of the Liberian market: mobile-first, data-conscious, mobile-money-aware.

- 🔭 Currently building demo/production sites for clients and refining my own product ideas
- 🌱 Sharpening TypeScript generics and testing (Jest, Playwright)
- 🎓 Completed **HNG Internship 14** — reached Stage 8 across React, Next.js, TypeScript, Vue, and SvelteKit
- 🏆 2nd Place — Queen Arit Circle Tech Hackathon (2025)
- 🌍 Long-term goal: working internationally while staying rooted in Liberian-market problem solving
- 💬 Ask me about Next.js, Supabase, or building for low-bandwidth / mobile-first users
